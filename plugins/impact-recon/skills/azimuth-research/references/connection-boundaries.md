# Public connection boundaries

This proposed public profile reads evidence and research guides only. Saving, personal candidate retrieval, private engagement access, graph writes and durable strategy storage are unavailable. Do not switch apps or call another connection's save/list tools. Return a source-backed conversation review note and explicitly state it has not been saved.

Use the configured Azimuth connection and its actual tool catalog. Guides describe research methods, not proof that every underlying data path exists. Native host research/documents supplement bounded MCP reads. `list_research_workflows` and `get_research_workflow` retrieve this library when available. Research instructions do not authorize sending, submitting, publishing or scheduling.
