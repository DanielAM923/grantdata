# Impact Recon — Claude plugin (alpha 0.5.2)

Read-only remote MCP (`https://emerald-mcp.redbeach-93eee11c.eastus.azurecontainerapps.io/mcp-public`), no sign-in, plus nine research guides as Claude skills. Early research tool: results may be incomplete or inaccurate, so check the linked evidence. Shared alpha usage limits apply. Saving and graph edits are unavailable.

## Install in Claude Code

```bash
claude plugin marketplace add DanielAM923/impact-recon
claude plugin install impact-recon@impact-recon
```

Tools only, without the skills:

```bash
claude mcp add --transport http --scope user impact-recon https://emerald-mcp.redbeach-93eee11c.eastus.azurecontainerapps.io/mcp-public
```

Developing from a checkout: `claude --plugin-dir <this directory>`.

## claude.ai and Claude Desktop

Add the same URL under **Customize → Connectors → Add custom connector** and choose **No sign in**. Skills are not needed there; the server exposes the same guides through `list_research_workflows` and `get_research_workflow`.
