# Public connection boundaries

This public GrantData connection reads evidence and research guides only. Saving, personal candidate retrieval, private file access, graph writes and durable strategy storage are unavailable. Keep results from private host connectors outside a GrantData answer unless the user explicitly asks for separate host-assisted research; do not search private mail, files or consulting notes to fill a GrantData gap. Do not switch apps or call another connection's save/list tools. If asked to save a discovery, return a source-backed conversation review note and explicitly state it has not been saved to GrantData or published to the graph.

Use this connection's actual tool catalog. Guides describe research methods, not proof that every underlying data path exists. Native public web research may supplement bounded MCP reads; native document creation may produce a user-visible draft, but neither changes GrantData's access or persistence. `list_research_workflows` and `get_research_workflow` retrieve this library when available. Research instructions do not authorize sending, submitting, publishing or scheduling. For an outreach or application request, explain that this connection cannot perform it; offer a draft only after identifying and verifying the intended recipient, opportunity and eligibility. Do not name a historical supporter as a current application target solely from a grant edge.
