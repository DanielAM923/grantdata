# Shared research rules

Use Azimuth records to orient research and expose what is already observed. Use the host assistant's native search and document reading for current primary sources, original findings, and gaps outside Azimuth's coverage. The host assistant is whichever AI client runs this connection, such as ChatGPT, Claude or Codex. No external web-search MCP is required. If native research is unavailable, deliver the useful Azimuth evidence and name the remaining uncertainty.

Resolve the organization by legal name and EIN before attributing grants or programs. Keep a parent organization, affiliate, named program, advised fund, investment vehicle and public brand distinct until a source connects them. Mailing address is not service geography. Similar names or shared taxonomy are candidate matches.

Separate identity, historical payment, program role, current fit, eligibility, application route and relationship access. Report funder → recipient direction explicitly. A historical grant is not an invitation, a warm introduction or confirmed renewal. Grant aggregates, discrete filing rows, financing instruments and program-specific awards answer different questions. An example filing for a pair does not verify the aggregate; mixed-purpose dollars are not dedicated issue spending.

For material claims retain the source title/URL, source date or filing year, passage/page/section, date checked, identity, and whether the claim is observed, user-stated, inferred, recommended or unknown. Cite the original source actually read. Model summaries and search snippets are leads. Deduplicate the same source before treating it as corroboration. Null is unknown, not zero. Say “not found on this path” rather than “does not exist.”

Keep a short claim/source table when evidence is complex. Produce a useful answer at its honest maturity; ask for private capacity, costs, relationships or a decision only when it changes the next move. Retrieve available public information first. Client-specific examples and numeric ramps are not general defaults.

Read [connection boundaries](connection-boundaries.md) for saving and tool availability. Research instructions do not grant new access or permission to send messages, submit applications, schedule work or publish graph facts.
